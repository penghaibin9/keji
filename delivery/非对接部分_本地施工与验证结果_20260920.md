## 六、你现在怎么检查

不需要你执行技术命令。打开隔离预览后按顺序看：

1. 工作总览 → 搜索业务 → 打开记录或通知。
2. 统一待办 → 切换类型 → 输入关键词 → 查询和翻页。
3. 基础配置与字典 → 修改中文显示 → 查看变更历史。
4. 规则与周期 → 新建或复制规则 → 试算 → 核对公式 → 启用。
5. 教师积分激励 → 选择中文项目计算 → 查看积分依据。
6. 组织规则 → 复制调整 → 试算 → 检查原规则仍在。
7. 操作日志与安全审计 → 选择模块、日期、结果 → 查看中文详情。

正式规则不要直接使用隔离测试示例。等学校确认业务办法后，再录入学校正式名称、组织、周期、指标、权重和目标值。

线上演示版继续保持现状。本地修改不构成生产发布授权，后续发布仍须完成目标环境核验、可恢复保护点、候选版本验证和明确切换。
