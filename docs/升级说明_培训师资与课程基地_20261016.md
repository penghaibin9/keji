# 升级说明：培训师资、课程标记与培训场地（2026-10-16）

依据《社会培训管理办法》补上培训师资、培训课程、培训基地、培训项目四块的缺口。**不改数据库结构，升级不用迁移**：新内容存在现有业务资料表的 JSON 字段里。

## 一、改了什么

| 业务 | 做法 | 谁办 |
| --- | --- | --- |
| 培训师申报（校内） | 老师在“业务办理”点“申报培训师”，选培训方向、引用已有资格，写资格依据 | 教研室 → 学院 → 学校（继续教育学院）→ 组织人事部认定（认定时必须写依据） |
| 外聘培训师登记 | 学院代外聘人员登记 | 学院登记 → 教务处备案审核（必须写依据） |
| 培训师资库 | 认定或备案通过后自动入库；学校可对库中人员做省级推荐记录 | 学校 |
| 培训课程 | 新增“培训包”“一人一技”标记，一人一技须写面向群体 | 申报人 |
| 培训基地 | 申请时选基地级别：校级、市级、省级及以上 | 申请人 |
| 培训项目 | 新申报和重新备案须填培训场地：校内基地、其他校内场所、校外；校外要登记一事一议（外出理由、议定文号或会议日期） | 申报人 |
| 开班前准备 | 项目详情里的清单：教学计划、师资安排、场地、设备、教材教具、培训告知书或邀请函 | 负责人、学院、学校勾选 |

## 二、上线前必须做的一步

“执行口径 → 配置审批职责”里新增两项职责，学校要指定人员，否则培训师走到对应一级会没人办：

- **培训师资格认定（组织人事部）**：办理校内培训师最后一级认定的人员。
- **外聘培训师备案（教务处）**：办理外聘人员备案的人员。

## 三、采用的默认答案

- 校内培训师四级审批；外聘两级。
- 师资库不设有效期和复审。
- 项目选主讲教师时只提示“已在师资库”，不拦截。
- 培训场地只要求新申报和重新备案填写，已备案的项目不追溯。
- 开班前准备清单只提醒，不影响审批和备案。

## 四、注意

- 外聘培训师的资质材料按现有规则脱敏显示（证书编号只露首尾）。
- 以上是对照办法的实现，超出招标文件范围的部分（培训师、一人一技、培训包、场地一事一议）建议在合同补充条款中确认。
