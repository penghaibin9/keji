# R5 接口连接生命周期与同步证据

## 一、从配置到真正可用

网页保存配置、本地字段试映射均不等于接通。管理员依次操作：配置 → 连接验证 → 查看验证结果 → 显式启用。验证必须来自部署方注册的真实适配器，当前配置摘要、适配器身份、固定 HTTPS 地址、固定密钥变量名、当前密钥指纹和最新验证记录全部一致；验证有效期 24 小时。

配置变更、重新验证或手动断开会撤销原连接使用状态并停用计划。密钥轮换、验证过期、部署适配器缺失时，有效状态即不再 CONNECTED；worker 不能继续外发或自动入库，计划在下次检查时停用。重新启用连接不自动恢复定时批准。

本包 **没有交付任何学校真实协议适配器、真实密钥或真实联调成功证据**。测试中模拟 REAL 分支的对象是明确的无网络协议替身，不能用于验收。生产注册表为空时如实保持 NOT_CONNECTED。

## 二、部署适配器契约

只允许部署人员通过 `ND_ADAPTER_MODULES` 配置受信任 Python 模块；模块须已随审核过的镜像交付，不接受网页输入模块或任意文件。每个模块提供 `register(registry)`，调用：

```python
registry.register_production(
    'middle', adapter,
    endpoint='https://由学校确认的固定主机及路径',
    credential_env='ND_SCHOOL_DATAHUB_SECRET',
)
```

以上是契约示意，不是可联通的实现。`adapter.adapter_id` 是明确版本标识；`probe(config=..., credential=..., timeout_seconds=10)` 完成真实鉴权、TLS 与协议检查，仅当返回三个严格布尔值 `authenticated/tls_verified/protocol_verified` 全为 true，服务端才记验证通过。adapter 必须自己真正执行传入的超时、TLS 验证、固定 DNS/重定向限制、响应大小限制和协议校验；本包不以一个 timeout 参数冒充这些网络能力已验收。

`send(data_type=..., payload=..., idempotency_key=..., config=..., credential=..., timeout_seconds=10)` 必须获得与远端业务约定一致的明确应答。适配器需把“确实已接纳”规范为 `accepted: true`；空对象、字符串 true、缺字段均不算成功。允许保留安全格式 code/receipt_id。相同业务键、数据类型、当前配置及内容生成稳定幂等键；远端也必须实际支持幂等或提供对账策略，不能由本地摘要推断远端绝不重复。

`pull(data_type=..., mode=..., cursor=..., limit=1000, config=..., credential=..., timeout_seconds=10)` 必须返回含 records 数组的对象；明确空数组可表示无变化，空对象不可以。真实分页、游标/版本、冲正和限频规则仍需学校文档确定。

网页只能填写已在部署侧固定的环境变量名称，不能选择数据库凭据等任意服务器变量。密钥本体不回显、不写入导出佐证。验证指纹只在数据库私有字段保存，对外序列化移除。

## 三、同步证据与异常

佐证接口 `/api/sync-tasks/{id}/evidence` 在学校管理员授权后下载任务、逐笔记录、每次尝试、请求与脱敏回执摘要。复用历史幂等记录时纳入本次数量核对；同批重复业务键拒绝；缺行、未知行状态或数量不匹配不会给出 DONE。失败按配置至少 3 次尝试，下一次运行有时间间隔，错误消息不保存上游凭据或原始异常正文。

摘要针对规范化/脱敏对象，**不是原始网络字节或对方签名**，不能独立充当责任方签认或端到端 exactly-once 证明。

## 四、入站从预览到正式主数据

预览校验教师组织/绑定账号角色、课程所属项目存在且有效；先导入主记录，再导入依赖记录。确认时重新核对权限、版本、映射配置、预览内容摘要、行数和关联数据，防止预览后主记录失效或内容变化。所有行重验后整批写入，保存点保护 worker 捕获异常后不会提交半批业务数据。

接口拉取先落预览；只有仍有效、当前管理员显式批准的计划可以自动确认。质量错误保留错误行和预览，不写正式主数据、不推进正式游标。接口、批准人或计划失效时阻断已排队任务。恢复后所有外部连接和计划重新验证/批准。

统一认证登录回调与退出、培训收入/课程人次上游粒度、湘培证书等权威来源仍按原联调指南向学校确认，不猜测协议、不拿教师资质替代学员证书。
