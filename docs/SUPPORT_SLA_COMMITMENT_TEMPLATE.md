# 售后与运维保障承诺模板

本模板按采购清单第14项整理，最终商务文本由双方合同/验收文件确认。

1. 免费质保期不少于1年，自最终验收合格之日起计算。
2. 严重故障30分钟内响应、2小时内提供处置方案；一般功能故障2小时内响应；普通咨询及配置问题1个工作日内响应。
3. 质保期内，学校组织机构、考核规则、统计口径及已对接接口的合理小幅调整提供配置、映射和适配支持；重大新增功能或新增系统接入另行确认。
4. 质保期后年度运维服务费原则上不高于合同金额10%，重大新增功能开发和第三方新增商业授权除外。
5. 学校业务数据、数据字典、字段映射、数据库结构、接口文档及学校专属业务配置归采购人所有；定制源码按合同交付或纳入采购人可控制的代码托管机制。
6. 合同终止或更换供应商时提供完整、结构化、可复用的数据和资料移交，不使用专有格式、加密字段或封闭接口限制迁移。
7. 提供管理员和经办人员培训、用户操作手册和必要运维说明。
