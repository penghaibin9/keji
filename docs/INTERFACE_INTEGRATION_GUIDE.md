# 外部接口联调指南

> R5 补充：连接验证/启用/失效、部署适配器契约及同步佐证以 `R5_INTEGRATION_LIFECYCLE.md` 为准。当前仍无学校真实适配器与联调成功证据。

## 1. 共同原则

统一认证、学校数据中台、湘培直通车均属于采购范围。当前代码已经提供接口登记、责任单位、HTTPS地址、鉴权模式、密钥环境变量名称、字段映射、数据类型目录、任务/逐笔记录、失败原因、重试/补传和审计底座；但没有真实学校/第三方协议、凭据和网络时，必须保持 `NOT_CONNECTED`。

真实密钥只放服务器 secret/环境变量，不录入网页、不写审计、不进入开放业务移交包。

## 2. 学校统一认证

已登记 `sso` 连接和 `identity` 字段映射目录，可以用脱敏身份报文验证账号/姓名/组织/角色或稳定身份标识的本地字段映射。当前本地密码登录用于独立施工和验收；正式 SSO 跳转、回调、登录状态校验和单点退出必须依据学校实际协议实现，不能预设 OAuth2/SAML/CAS 或自定义协议中的任何一种。

联调需要学校提供：正式协议/文档、测试地址、身份字段字典、角色与组织映射、鉴权/签名规则、退出机制、测试账号、网络可达条件和错误码。

## 3. 学校数据中台

采购目录包括教师人事、培训收入、课程人次、培训项目、课程基础信息。平台已建立教师 HR 档案、项目/课程/班级主数据和培训业务事实底座；教师人事、项目、课程支持“字段映射 → 入站预览 → 逐行错误 → 明确确认 → 正式入库”。教师组织或启停变化会提升 auth_version，使旧会话失效。

培训收入和课程人次已有本地正式业务事实，但上游实际粒度/主键/更正语义必须由学校字段字典确认后再决定自动入站契约，不能自行猜测并造成重复收入或重复人次。

平台内部已经具备 FULL 全量、INCREMENTAL 增量、人工触发和定时计划四种执行模式：worker 会按计划创建拉取任务、保存游标、生成入站预览，并且只有学校管理员明确批准“自动确认入库”后才允许定时批次自动写正式主数据。批准人停用/降权、接口掉线或拉取适配器不可用时，计划自动停用并留痕。

但真正的分页、更新时间戳/游标含义、限频、签名/Token 和返回报文必须依据学校真实接口实现 `pull()` 适配器。当前生产适配器注册表为空，三类连接保持 `NOT_CONNECTED`，因此上述执行模式是正式内部底座，不是外部接口已经联通的证据。

## 4. 湘培直通车

采购数据目录已逐项显式展示。平台当前已有本地来源的项目、课程、班级、教师授课、人次、培训记录、考核结果；培训计划、学习过程、结业结果、证书信息若学校没有对应本地权威来源，会标 `WAITING_SOURCE`，不得用教师资质证书冒充学员结业证书。

外发任务按业务键+数据类型+payload 生成幂等键，逐笔保存请求摘要、尝试次数、返回码和处理结果；配置重试次数最低为3，支持单条和批量失败补传，旧失败日志不覆盖。

## 5. 联调结束判定

只有真实网络调用、字段映射、脱敏真实样本、异常返回、重试、重复提交和责任方签认均有证据，才允许将对应连接置为正式已接通。配置页保存或本地字段校验本身不构成联调成功证据。

## R8内部适配器契约补充（不是学校实际协议）

`retry_count`含义为首次发送之后的重试次数；值为3时最多首次+3次。人工重新授权补传开启新的有界尝试周期，原业务幂等键及累计尝试号不变。外部接收方的幂等保证须在真实联调中验证。

映射`required`必须是JSON布尔true/false，不能使用字符串。整数不能以1.5等小数截断得到，数值禁止NaN/Infinity。HR的`source_updated_at`提供时必须含时区；已有版本不得被旧时间或缺时间报文覆盖。

公共入站处理的是不超过1000行的完整单元。出现`has_more=true`、`complete=false`、`truncated=true`，或者游标不是有效有界字符串时，系统不会标记完整同步或前推成功游标。真实分页、全量完成证据和跨单元断点恢复必须由学校接口责任方与适配器实现共同确认，不能忽略部分页标志。

详细规则、测试与实际未完成条件见 `R8_RELIABILITY_CLOSEOUT.md`。
