# 数据字典与移交说明

## 1. 数据类别

核心数据分为组织/角色/用户与基础配置、培训授课业务事实、教师参训事实、教师资质及历史版本、积分流水、教师考核、组织考核及逐指标证据、核对/工作流、项目/课程/班级主数据、教师 HR 档案、接口连接/入站批次/逐笔同步记录、审计和附件。

授课业务事实与教师参训事实严格分开，防止教师参加培训的学习时数被计为其授课贡献或重复累计培训收入/课程人次。

## 2. 在线数据字典

学校管理员可以从“运维与交付”下载“平台初始化配置与数据字典.xlsx”。该工作簿从当前数据库模型和实际学校配置生成，包含组织机构、角色权限、参数与字典、周期、接口登记、接口数据类型和数据库字段字典。

## 3. 开放业务移交包

学校管理员可创建 handover 后台任务。ZIP 采用开放 UTF-8 CSV + JSON + 原始附件格式，包括数据库结构、初始化配置、接口数据目录和附件 manifest。`scripts/verify_handover.py` 会核对安全路径、文件集合、大小、SHA256、附件字节和敏感认证字段。

明确不移交：密码哈希、登录会话、登录节流、命令幂等回执、附件内部存储键和外部接口密钥值。接口配置只允许出现密钥环境变量名称。

开放业务移交验证通过不等于灾备恢复通过。灾备恢复需要 MySQL dump、附件和配置在独立空实例完成恢复演练。
