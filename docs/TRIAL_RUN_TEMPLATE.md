## 二、试运行计划

### 2.1 目标

1. 在学校指定服务器上验证四级角色日常业务闭环可用：门户待办、培训台账、资质审核、积分确认、三级考核、组织考核、导入导出、审计查询。
2. 使用脱敏真实数据验证关键业务计算结果正确（积分、考核双轨比对一致率 100%）。
3. 验证三类外部接口在真实环境的连通、字段映射、异常与重试（已具备学校资料的接口）。
4. 验证性能指标、备份与独立恢复、日常运维流程。
5. 收集问题并完成整改，形成是否进入最终验收的结论。
