# 数据字典（字段级）

> 适用版本：R11（Alembic 基线迁移 `20260918_0001_canonical_fresh_school`）。本文件由脚本根据 `backend/app/models.py`、`reference_data.py`、`integrations.py`、`inbound_sync.py`、`org_assessment.py`、`installation.py` 中的 SQLAlchemy 模型逐字段生成，并与基线迁移脚本逐表核对；中文含义与状态取值依据后端代码和 `settings_catalog.py` 默认状态显示名整理。对应采购条款 4.7（数据字典）、13.6（交付资料）、14.5（数据库结构归采购人所有）。

## 0. 通用约定

- 数据库：生产为 MySQL 8.4（utf8mb4），测试为 SQLite；主键统一为 36 位 UUID 字符串（个别表以业务键为主键，见各表）。
- 时间：所有 `DATETIME` 均为 UTC，无时区存储；日期为 `DATE`。金额、学时、分值使用 `DECIMAL`，不使用浮点。
- 通用字段：`id` 主键；`created_at` 创建时间（UTC）；`version` 乐观锁版本号（写请求携带 `expected_version`，不一致返回 409“数据已被其他操作更新，请刷新核对”）。
- 状态码与中文显示名：状态码及合法流转由服务端固定；中文显示名默认值见 `settings_catalog.STATUS_LABEL_DEFAULTS`，学校可在“基础配置与字典 → 业务字典 status_labels”中修改显示名，但不能新增状态。
- 【敏感】字段：不在接口响应（`core.SECRET_COLUMNS`）、Excel 导出和开放移交包中输出。移交包排除：password_hash、auth_version、failures、locked_until、storage_key、token_hash、csrf、lease_token、lease_until，以及 auth_sessions、login_throttles、command_receipts、installation_provenance、runtime_state、mutation_guards 整表。
- 列说明：“可空”=是否允许 NULL；“键/索引”中 PK=主键、FK=外键、UNIQUE=唯一、INDEX=单列索引。
- 在线版本：学校管理员可在“运维与交付”下载《平台初始化配置与数据字典.xlsx》（`GET /api/delivery/configuration.xlsx`，“数据库字典”工作表从运行库模型实时生成）；开放移交包内 `database_structure.json`、`delivery/database_dictionary.json` 为同源结构。
