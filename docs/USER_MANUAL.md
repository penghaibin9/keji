# 用户操作手册（2026年10月12日交付收口版）

适用于湖南科技职业学院一站式非学历教育智慧前台。菜单随本人角色与已授权限变化；本手册的菜单、页签及按钮已按当前前端源码核对，见《手册菜单按钮核对表》。本文说明当前程序行为，不代表学校真实统一认证、数据中台或最终验收已经通过。

## 一、共同操作：登录与本人身份

在学校提供的正式访问地址打开系统。输入管理员开通的账号和密码，点击“登录工作台”。本地账号首次登录必须完成“首次登录修改临时密码”，填写当前密码及新密码，点击“修改并重新登录”；新密码至少12位，不能只有数字或只有字母。修改后旧会话失效，需要重新登录。

登录页只有在统一认证入口已具备条件时显示“学校统一认证登录”。正常统一认证会话使用学校认证结果，不要求修改本系统临时密码；随后改用本地账号登录时，尚未完成的首次改密要求仍然有效。统一认证识别身份，本地账号的组织、角色、状态和职责决定权限；认证成功不会自动成为管理员。看不到认证按钮或认证失败时联系学校信息中心，不向别人提供本人密码。

进入系统先核对本人姓名、所属组织和角色。“人事调岗 · 授权待确认”表示人员组织发生变化，原授权暂不能继续使用。请学校管理员核验新组织和角色后确认授权，用户重新登录；不要借用别人的账号。

“工作总览”显示本人范围的待办和统计；“统一待办”集中办理事项。“查询”“重置”“上一页”“下一页”用于查找，统计周期与待办办理范围不是同一概念。详情内“查看下一条”只打开下一条；“通过并查看下一条”“确认并查看下一条”“归档并查看下一条”会先执行当前办理，再打开下一条。仍须逐条核对材料和计算结果。

## 二、教师：本人数据、积分申报与考核

### 1. 查看培训和授课学分

进入“个人培训”查看本人培训事项；“培训数据”核对授课与参训记录。进入“授课与学分”查看学年、两学期、教务与超星的学分及课程明细。没有账号对应、课程缺学分、人员信息缺失等提示，不能当作正常零学分。

从教务、超星拉来的课先显示“待认定”，教研室主任认定后才计入学分、学时和积分；“已认定学分”只算已认定的课，“待认定”单列。主任认定为“不计分”的课会显示原因和认定人。以后重新拉取时，某门课的学分或学时有变化，会自动回到“待认定”，请主任重新认定。

教务和超星来源内容需在源系统更正，本系统不直接改学校课程学分。有误先联系教务处或超星管理员；已影响积分或考核时，在“数据核对与复核”提出核对，办结后再由有权人员计算。当前学校真实数据接入情况以信息中心联调记录为准。

### 2. 社会培训积分申报

进入“教师积分激励”中的“社会培训积分申报与认定”，按实际可见项目进行“本人积分申报”。选择项目和周期，填写需要的授课或辅助工作依据，上传认定表照片或扫描件。材料可以一次选择多份；逐份显示上传结果。缺失材料、上传失败、职责缺人或制度口径未确认时不能把草稿当作已提交。

默认勾选保存后直接提交审批；去掉勾选则只保存草稿。提交后按院长初审、归口复审、分管副校长审批、教学秘书归档流转。本人不得审核本人的申报。

退回后打开“补正及辅助积分”。同页显示“退回意见与已有材料”，原来正确的填写内容与材料保留，不需要全部重传；补齐后使用“保存补正并重新提交”。材料部分失败时按提示补传失败材料。页面提示已保存但尚未提交时，先处理提示原因，再在详情使用“提交本人积分申报”。不要重复新建同一申报。

只有“归档并计入个人台账”完成，才进入相应个人台账。已归档内容不能直接改写；需要更正时使用“申请追加更正”，填写原因和依据，按复核与审批流程追加差额，保留原记录。

### 3. 资质、积分确认与考核

“教师资质管理”用于本人资质草稿、佐证附件、提交和退回补充。“教师积分激励”中的“确认本人积分”或“积分核对与确认”用于查看明细、依据和本人确认；发现异常先提出核对。

“三级考核管理”中的“三级考核”查看本人结果和各指标依据。确认前核对周期、规则版本和来源；有未解决数据核对或计算来源变化时不能继续确认。已归档结果使用冻结证据，当前组织或规则调整不会自动改写历史结果。

导出任务进入“导出下载”；只有生成完成并仍具备相应权限时才能下载。导出范围为本人授权数据。

## 三、教研室：本组织核对与办理

教研室管理人员查看本教研室范围，通过“学院与教研室”及“统一待办”进入具体事项。可在相应授权下核对培训数据、审核资质、办理教师考核教研室环节及数据复核；社会培训流程还须具备对应审批职责，角色本身不替代职责。

教师考核核对无误后使用“确认并提交学院”；有问题填写具体意见，使用“退回教师核对”。本人事项需要由其他符合权限及回避要求的人员办理。关闭详情后保留原筛选和页码，按列表继续办理。

授课认定：本教研室老师有待认定的课时，“统一待办”会出现“授课认定”。也可以在“授课与学分”勾选“只看待认定的”，点“去认定”打开该老师该学年的两学期明细，勾选课程后点“认定计分”“不计分”（必须写原因）或“改回待认定”；待认定的课已默认勾选，可以一次办理多门。缺学分的课不能认定计分，请先请教务处补齐，或认定不计分。教研室主任本人的课由学院负责人认定；工号还没有对应账号的由学校系统管理员认定。每次认定都会留审计记录。还有待认定的课时，学校正式计算授课学分积分会被拦下并提示哪些课待认定。

表格业务从“表格导入导出”中的“表格导入”进入；只有导出权限时菜单可能直接显示“导出下载”。按标准模板填写，不修改固定表头，不用截图替代表格。

## 四、二级学院：学院范围与社会培训管理

学院人员可查看本学院及其启用下属教研室。通过“培训项目管理”“培训课程管理”“培训基地管理”“培训成果”及“学院台账与口径检查”维护有权办理的业务。项目备案、结项核验、成果认定和学院台账分别有材料与依据要求；页面保存成功不表示备案、结项或学校认定已经完成。

积分认定由获授院长职责的人员初审。教师考核学院环节使用“确认并提交学校审核”；其他环节不得越级处理。进入“三级考核管理”的“学院社会培训年度考核”填写或核对学院年度自评，按财务、成果、纪检核验及委员会评审的实际职责办理；制度口径未确认时不能发布正式结果。

学院统计和个人积分分配口径分别核对，不能用“本页”条数代表全院全部历史数据。归档件与追加更正件分别保留，不删除旧证据来修正分数。

## 五、学校管理员及归口：授权、规则与集中办理

### 1. 账号、职责和口径

“账号与权限”维护组织、账号与角色。人事调岗导致暂停授权时，打开账号“编辑”，核对新组织和角色，使用“确认授权并保存”；保存会使旧会话失效。教师和教研室角色绑定教研室，学院角色绑定学院，学校角色绑定学校根组织。

“规则与配置”包括“考核周期与规则”“社会培训制度口径”“字典与参数”。新组织考核规则的“归属培训收入”达标值须按学校考核细则填写，不靠默认数值启用。规则须完成试算后明确启用；修改既有制度用新版本，不改历史归档成绩。

在“社会培训制度口径”通过“配置审批职责”登记院长、归口、分管副校长、教学秘书及财务、成果、纪检、委员会职责。保留可替代办理人员，保证本人回避后仍有人可办。执行口径、校历和退回补正期限应有学校书面依据；缺失时先补学校材料，不能编造默认值。

### 2. 待归档与批量办理

“统一待办”里的“待归档清单”列出待归档的积分认定、更正和教师考核；使用“返回全部待办”返回。已审批通过不等于已归档入账。

批量仅开放社会培训积分认定与教师考核两类，且只勾选当前页默认20条以内的事项，不跨页自动全选。必须同一业务、同一环节，且当前人员有权办理；本人事项不能勾选。页面按环节显示“批量确认所选”“批量审核所选”“批量归档所选”。

先逐条核对材料与计算依据，再勾选“逐条核对确认”。每条重新读最新版本，分别执行权限、回避、来源变化和未解决核对校验，分别留痕。结果区分成功和未办理，失败项显示具体原因；处理原因后再单独办理或重新选择失败项，不把整批点击当作整批成功。

### 3. 表格导入与代码对照

下载模板 →“上传表格”→ 查看预览。无错误批次仍为“待确认导入”，点击“确认入库”后才真实写入。有错误批次显示“导入有误”，整批不入库；可“下载错误明细”，修正原文件后重新上传，或“放弃本批”并填写原因。放弃后状态为“已放弃”，原预览、错误明细与审计记录保留；旧数据中有错误的待确认批次也可以放弃。

“对接与同步”中的“代码对照（学校码表）”登记在职状态、教职工类别、单位、学历、学位、课程性质的学校对照。按提示导入，保存会替换这一类码表，应先确认是完整的学校版本。未导入的代码保留原码并标“待码表”；在职状态码表未到时人事同步会明确阻断，不自行猜人员是否在职。

学校数据中台只取约定的四张表；培训项目、人次和收入由录入或表格导入产生。保存接口参数、本地字段校验、采集任务结束与确认入库分别核对，不能互相代替。真实凭据在学校受控服务器配置，页面不填写或回显密钥。

## 六、常见提示的处理

| 提示或情形 | 含义与处理 |
|---|---|
| 执行口径待确认、口径尚未确认启用 | 缺学校书面依据或尚未启用对应版本；联系社会培训管理员核实，不猜默认计分。 |
| 已保存草稿、补正已保存，尚未提交 | 内容已保存，提交步骤尚未完成；核对材料、职责、期限口径等提示，再在原记录提交。 |
| 人事调岗 · 授权待确认 | 原人事单位变化，联系学校管理员重新确认组织与角色后登录。 |
| 待码表、在职状态码表还没导入 | 学校代码还未有权威解释；取得码表后导入，在职状态缺码表会阻断同步。 |
| 版本冲突、办理环节已变化 | 别人已处理或数据已变化；重新打开原记录，核对后办理。 |
| 计算依据已变化、核对尚未完成 | 暂停确认和归档；先复核来源，按流程重算或处理核对。 |
| 导入有误、已放弃 | 前者整批未入库，后者明确终止本批；下载错误明细修正后另传，保留原审计。 |
| 待对接、未接通 / 已阻断 | 检查真实连接条件与学校资料，不把本地验证当作学校联通。 |

学校真实登录、四角色业务、打印分页、附件兼容、备份恢复、性能与双轨计分仍须现场按验收清单签认。
