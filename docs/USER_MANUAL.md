# R11 用户操作手册｜非学历教育智慧前台

适用：R11 新版页面接入 R10 业务工程。页面显示的身份、菜单、状态和数据来自实际后端，不再提供设计稿的角色切换或示例保存。正式系统需要服务端启动，不能把 frontend/index.html 当单文件原型双击使用。

## 1. 进入系统与认识首页

1. 使用管理员提供的本地账号登录；首次登录按提示修改密码。当前未交付学校正式统一认证适配器，本地登录不等于学校单点登录。
2. 查看右上角本人身份和组织。实际角色由服务端决定，不能从页面切换成管理员。
3. 首页依次是三类系统入口、筛选与核心指标、收入趋势、待办、考核进度和通知。教师只能看本人授权范围；学校连接的配置入口仅向有权限的人员开放。
4. 点击“展开筛选”选择周期、时间、项目等条件；教师活动总览明确标注“全部历史”，不要当作当前周期统计。培训台账的参训列表按所选周期与日期的交集查询。
5. 趋势图来自实际月度金额，可展开精确金额表。没有数据就显示空状态；错误响应不会换成示例数字。

## 2. 教师高频操作

**培训台账**：进入“培训台账”→按时间/项目/课程筛选→分别查看授课记录和本人参训记录。两张列表各有自己的上一页、下一页，不会被另一张表的条数锁住。详情内核对来源与业务值；有异议按现有核对申请流程处理。

**资质材料**：进入“教师资质”→新增或打开本人资质→填写证书信息及依据→上传附件→提交。被退回后打开同一记录查看意见、补正并重交；不能绕开状态直接改已确认历史。已经用于归档考核的当期原附件仍按原证据下载。

**积分与考核**：进入积分明细核对来源、规则和计算结果；需要复核时填写原因及依据。进入三级考核的教师页签打开本人结果，查看指标与办理轨迹，再确认或提出异议。已归档件使用冻结依据，不会因当前姓名、组织或规则调整而静默改写。

## 3. 教研室与学院办理

1. 进入“分级管理”，确认当前组织范围。
2. 查看待办。教师事项和本组织授权范围内的组织考核都能进入办理入口，不混入其他组织或全校接口异常。
3. 打开对应资质/考核，查看明细与依据，再确认或退回；退回需填意见。
4. 三级考核中教师、教研室、学院、学校各页签沿用真实接口；组织列表分页传给后端，排名仍限定同周期、层级和规则。
5. 导出与打印继续使用现有授权与冻结结果接口。真实浏览器打印分页尚待部署后验收，不以离线截图替代。

## 4. 学校管理员：从对接中心开始

进入“系统对接中心”，分别管理学校统一认证、学校数据中台、湘培直通车。先打开“对接怎么开始”，下载空白 Excel 沟通清单，联系学校信息中心、业务负责人及对方系统责任人填写。清单不是接通证明，不填真实密码、令牌或教师敏感资料。

### 4.1 维护参数与字段对应

1. 在对应系统的“接入概况”维护接口地址、责任单位、鉴权方式和密钥环境变量名。没有正式协议时不要凭名称猜测；页面不收取密钥值。
2. 在“字段对应”点击编辑，逐行选择采购数据类型，填写对方字段、平台字段、转换方式、必填和默认值。默认值留空表示不设置；文字默认值必须是 JSON 字符串。
3. 保存后重新打开核对。操作必须通过后端的版本、权限和审计校验；配置变更会使旧验证或计划批准失效。
4. 可以用经双方确认的脱敏样本执行本地字段校验，但它不调用外部系统，也不是生产连接验证。

### 4.2 学校数据中台

“入站预览”支持现有教师人事、项目和课程的预览链。粘贴经确认的报文后先查看错误与关联；无错误时仍需管理员点击确认，才写入正式主数据。明细可翻页，已入库批次明确显示已入库；预览通过不显示成业务成功。

“采集任务”按当前接口、类型、状态与页码查询，查看失败原因及任务详情。任务的 DONE 仅表示该任务步骤结束，不能替代入站批次 COMMITTED 回执。

“定时计划”沿用真实连接、适配器、自动入库批准及授权失效保护。尚无真实适配器时，不能启用计划让它假装同步。

收入/课程人次已有本地业务事实，但真实自动入站、分页、游标、更新/冲正语义仍需双方协议与后续适配开发。

### 4.3 统一认证和湘培

统一认证页展示身份与组织映射、参数和验证记录，当前不是完整的学校 SSO 登录适配。真实协议、回调、身份校验与退出需另外完成。

湘培页提供采购目录、同步任务、逐笔结果、单条补传和原任务批量补传入口。培训计划、学习过程、结业结果、证书信息仍待权威来源，不拿教师资质证书替代学员结业证书。失败/缺适配器不显示成功；旧失败记录和幂等键继续保留。

### 4.4 验证与明确启用

查看“验证与启用”的当次校验结果、逻辑版本和到期时间。历史验证通过不等于当前连接仍有效；TEST/本地通过不能启用。只有后端核验合格的真实证明才可明确启用，未知/失效/缺适配器仍拒绝。

## 5. Excel、导出与权限变化

导入：下载当前模板 → 上传 → 查看预览 → 下载错误行 → 修正并重传 → 明确确认。旧预览缺摘要/授权证明、人员调动或权限变化后会要求重新上传核对，不自动补造历史证明。

导出：在业务页面发起 → 到“导出与任务中心”等待 → 完成后下载。排队后撤权或停用仍会拒绝执行/下载，不因发起过任务永久授予权限。

## 6. 常见提示

| 提示 | 怎么处理 |
|---|---|
| 待对接 / 未接通 | 找信息中心收集真实协议，实施人员适配并联调；不要把保存参数当接通。 |
| 版本冲突 | 重新打开记录核对别人是否已处理，不重复盲点提交。 |
| 预览仍有错误 | 修正原数据或字段对应后重新预览，不能跳过确认校验。 |
| 当前账号无权 | 请管理员核对角色和组织，不通过改网址或借用账号绕过。 |
| 网络失败 | 页面会报错，不会用示例数据兜底；恢复网络后重新读取。 |
| 归档证据不一致 | 暂停办理并由实施人员核查，不能自行改分、重签摘要或删除历史。 |

## 7. 技术与验收边界

本版不改数据库结构，仍仅支持 canonical 新空校安装。完整代码包不包含 Docker 镜像、已安装依赖、学校凭据或证书私钥。前台接入现有本地业务，不代表三类外部系统已经接通；MySQL、原生浏览器办理与打印、性能、真实样本双轨及学校签认仍需完成。部署入口见 docs/R11_FRONTEND_INTEGRATION.md。

## 8. 2026年9月20日本地业务功能补充

本节只说明本地业务操作，不改变三大接口的待对接状态，也不代表线上演示版已更新。

1. **查业务**：点击顶部搜索；窄屏保留放大镜按钮，也可按键盘斜杠键打开。输入关键词后点击“搜索业务”，可查本人授权范围内的培训记录、资质和已发布通知。菜单可直接筛选；业务结果超过显示上限时进入相应台账继续查询。
2. **办待办**：进入“统一待办”，选事项类型、填关键词、点“查询”；通过上一页、下一页查看其他事项。教研室和学院工作台的待办保持组织授权范围，不因统计周期筛选隐藏其他周期应办事项。
3. **改显示名称**：进入“基础配置与字典”→选择业务字典→修改配置。直接编辑中文状态名称，不填写程序字段；填写原因后保存。“变更历史”以中文业务表格对比各版本，不能改变审批环节。
4. **建教师规则**：进入“规则与周期”→新增教师规则→选类型和开放周期→填写指标名称、来源、系数或权重等→保存草稿→选择教师试算→核对公式和总分→启用。系统自动产生内部编号，无需输入代码。
5. **算积分**：进入“教师积分激励”→计算入口→选周期和教师。系统显示该周期生效的中文积分项目；不勾选项目表示计算全部，勾选则只算指定项目。没有生效规则时不能提交。核对写入条数后，在积分明细查看规则名称、计算时间和公式。
6. **改组织规则**：进入组织规则详情→复制为新版本→修改新名称、目标周期和指标→保存新草稿→选择组织试算→检查逐项结果→启用。旧规则、旧试算及历史成绩不被覆盖；复制后的新草稿必须重新试算。
7. **查操作记录**：进入“操作日志与安全审计”，按关键词、业务模块、结果、日期筛选。详情以中文显示已识别业务字段；内部技术字段和敏感值不直接铺在客户页面。
8. **看导出**：导出任务显示文件大小、生成状态和下载说明；后台没有返回行数时显示“以下载文件为准”，不虚报零条。下载依然重新检查权限。

“实施人员使用”默认折叠的内容是排错依据，客户正常办理不需要打开。遇到输入错误时按中文提示修改，保留请求编号便于技术人员排查，不要连续重复提交。

## 9. 工作总览：先办事，再看统计

1. 登录后先核对姓名、角色与“查看范围”。教师只显示本人，其他角色显示其授权组织。
2. 在“待办理”查看当前事项；退回补充和数据核对优先。首页最多展示6项，“全部待办”可继续查询和翻页。
3. 点击“查看事项”进入原有业务详情。首页不会直接执行审核、重算、确认或归档，业务校验仍在原流程完成。
4. “常用操作”根据当前角色与权限生成。教师入口为本人的培训、资质、积分和考核；管理人员看到其授权的办理和统计入口。
5. “资质有效期提醒”与待办理分开计数，按真实有效期与学校配置生成，最多展示最早到期的4份；“资质待办”进入包含资质补正、审核和提醒的统一待办分类。
6. 下方“统计周期”和“更多统计筛选”只影响业务概况，不隐藏其他周期待办和资质提醒。已有高级条件会自动展开，避免忘记正在筛选。
7. 学校管理角色可以在页面底部展开“学校接口状态”。其他角色不显示对接管理信息；状态仍来自后台真实连接记录。

首页数据读取失败时会明确报错并提供重新读取，不把失败显示成“没有待办”。本次只是本地工作台设计改版，不代表线上更新或学校正式验收。
