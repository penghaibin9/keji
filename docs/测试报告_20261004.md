## 三、性能

| 测什么 | 结果 |
|---|---|
| 全校同比 / 环比统计（13.7 本机最慢的一项） | 优化后单次请求从 0.89 秒降到 0.20 秒，**结果与优化前逐字节一致** |
| 3000 人在线、100 人并发（13.7、13.8） | 见 `delivery/performance-20261003/性能测试报告.md`。普通页面达标，复杂查询基本达标 |

本次测试机只有 2 个 CPU 核，数据库、系统和压测程序挤在同一台机器上，压测数字偏差，不能代表学校服务器的水平。13.7、13.8 的正式结论以学校服务器上的复测为准。

## 四、结论

- 自动测试在 Linux 上全部通过，没有遗留失败。
- MySQL 测试功能全部通过。还差在 MySQL 8.4 和学校服务器上复测。
- 双轨比对（9.7、10.7）要等学校提供考核办法和真实案例后再做。
