# 系统内操作手册与逐页填写指南

适用版本：20261022。系统内通过页面标题旁“使用帮助”、表单“填写说明”和“帮助中心”查看；下载或打印使用帮助中心的完整手册入口。

所有教学资料均为虚构示例，不代表学校制度确认或真实接口验收。

## 老师 5 分钟上手

第一次用系统的老师先看这一页：登录、切换身份、申报课程、看退回意见、重新提交、找待办，六件事就够日常使用。

1. 登录：打开系统首页，学校开通统一认证时用“学校统一认证”登录；没有开通时点“本地账号登录”，输入管理员发给你的账号和密码。第一次用临时密码登录，系统会要求改成至少 12 位的新密码。

2. 切换身份：右上角显示你现在的身份。兼任教研室负责人、学院负责人的老师，点右上角姓名，在列表里选另一个身份；办本人申报用“教师”身份，审核别人的申请用负责人身份。

3. 申报课程：左侧菜单“培训业务 → 培训课程”，点“新申报一门培训课程”。可以“从我的课程导入”（教务、超星课程自动带出名称和学分），也可以“手动填写课程”。带“*”的必填，写完点“提交申报”。

4. 看退回意见：申请被退回时，首页“待我处理”和“待办中心”都会出现提醒。打开这条申请，在办理记录里看审核人写的退回原因。

5. 重新提交：在申请详情里点“补正资料”，只改退回意见指出的地方，原来正确的内容和附件不用重填；点“保存补正”后，一定还要点“重新提交”，只保存不会回到审核人那里。

6. 找待办：点右上角铃铛或左侧“工作台 → 待办中心”。“待我处理”是需要你办的事，“我的申请”是你提交的申请，每条都能看到现在走到哪一步、由谁办理。

完成标志：能自己登录、交一份课程申报，并能在“我的申请”里看到它走到了哪一步。

## 登录、身份与密码

用本人账号登录，确认当前身份和所属组织后再办业务。

1. 学校开通统一认证时用“学校统一认证”登录；没有开通时点“本地账号登录”，用管理员开通的账号登录。

2. 第一次用临时密码登录时，按提示改成新密码：至少 12 位，不能全是数字或全是字母；改完会要求重新登录。

3. 登录后先看右上角的姓名和身份。兼任负责人的老师点姓名切换身份；忘记密码请联系学校管理员重置，不要借用别人的账号。

完成标志：右上角显示的是本人姓名和正确身份。切换身份只改变你现在用哪个身份办事，不会多给权限。

## 首页

每天打开系统先看首页：待我处理、我的申请、我的超星课都在这里。

1. 核对右上角的姓名、所属组织和当前身份。

2. “待我处理”列出需要你补充、核对或确认的事，点“全部待办”看完整清单。

3. “我的超星课”卡片显示你作为建课人的超星课程：本学年在用几门、已认定多少学分、有几门需要处理（缺学分或申报被退回）。点“全部 N 门”进入课程列表；超星课没显示时，在课程页点“认领我的超星课程”。

4. 右侧“业务办理”可以直接申报培训课程、培训项目、培训基地和培训师。

完成标志：知道今天有哪些事要办，并能从首页直接进入对应业务。

## 待办中心

把“需要我办的事”和“我交的申请”分开看。

1. “待我处理”是需要你办理的事项，“我的申请”是你提交的申请。

2. 可以按业务类型、状态筛选，点开一条查看材料、办理记录和当前办理人。

3. 审核人在详情里写好意见后通过或退回；申请人在“我的申请”里看进度，不要重复新建。

完成标志：办理后事项进入下一环节，或显示具体退回意见。点完按钮请回看结果。

## 培训课程（我的申报）

把适合面向社会开设的课程申报进学校培训课程库。

1. 左侧“培训业务 → 培训课程”，点“新申报一门培训课程”。

2. 有现成课程时选“从我的课程导入”，系统带出课程名称、学分、学时；没有就选“手动填写课程”。超星课程也可以在“我的课程 → 超星课程”里直接点“申报为培训课程”。

3. 填写课程名称、学时、教学方式、面向对象和课程简介，上传需要的材料后点“提交申报”。流程是学院审批、学校审批。

4. 被退回时打开申请，点“补正资料”按意见修改，点“保存补正”后再点“重新提交”。

完成标志：学校审批通过后显示“已入培训课程库”。课程入库本身不产生积分，积分按你在培训项目里的授课人次另行认定。

### 新填一门培训课程（教师）：填写说明

必填性会随选择变化，以当前表单提示为准。

| 填写项 | 含义、示例与限制 |
| --- | --- |
| 课程编号（必填） | 填写课程材料上的编号，例如 SOC-2026-001；被退回补正时保留原来的编号。 |
| 课程名称（必填） | 填写课程的完整名称，与课程材料一致，例如“社区营养配餐”。 |
| 学时（必填） | 按培训实际安排填写学时，可以填 0.5 学时这样的半学时；不要把分钟数直接填进来。 |
| 教学方式（单选）（必填） | 按实际教学组织方式选择，与培训方案一致。 |
| 思政属性（单选）（必填） | 按课程实际安排选择思政属性。 |
| 课程简介（选填） | 说明面向哪些社会学员、培训什么内容、学完能掌握什么技能。最多 2000 字。 |
| 选择关联项目（选填） | 选择这门课所属的培训项目，系统自动带出项目编号，不用手填；页面标为选填时可以不关联。 |
| 培训包（选填） | 只有按成套教学包开发的课程才勾选。 |
| “一人一技”专项（选填） | 属于“一人一技”专项培训行动时勾选，勾选后要填写重点群体与行动对接。 |
| 重点群体与行动对接（选填） | 勾选“一人一技”专项时必填：写清面向哪些重点群体、怎样对接行动，例如“脱贫人口、返乡青年；结业后推荐就业”。最多 1000 字。 |
| 课件审查状态（选填） | 学院已经做过课件审查、有审查记录时才勾选。 |
| 审查人或审查组（选填） | 勾选了课件审查状态时必填：填写实际做审查的人或审查组，例如“学院课件审查组”。 |
| 审查日期（选填） | 填写课件审查记录上的日期。 |
| 审查记录编号（选填） | 填写审查记录编号，方便核查；没有编号可以不填。示例：KJ-2026-03。 |
| 课程封面（选填） | 可以上传一张课程展示图片，只用于列表展示，不能代替证明材料。支持 PNG、JPG，单个不超过 5MB，只能上传 1 份。 |
| 本次申报说明（选填） | 写清申报依据，或需要审核人员了解的情况；被退回后重新提交时，说明按意见改了哪些地方。最多 2000 字。 |

## 培训项目（我的申报）

以本人为项目负责人申报培训项目，学院审批后由学校备案。

1. 左侧“培训业务 → 培训项目”，点“新申报一个培训项目”。

2. 按分区填写项目名称、起止日期、总学时、受众群体、服务面向、教学实施方式和培训场地；带“*”的为必填。

3. 上传项目方案等材料，保存草稿或直接提交，在“待办中心 → 我的申请”看办理进度。

完成标志：学校备案后项目显示为“已备案”。只保存草稿不算备案。

### 申报培训项目（教师）：填写说明

必填性会随选择变化，以当前表单提示为准。

| 填写项 | 含义、示例与限制 |
| --- | --- |
| 项目编号（必填） | 填写项目材料上的编号；不清楚时先向学院核实，不要自己编。示例：SOC-2026-01。 |
| 项目名称（必填） | 填写项目的完整名称，与培训方案一致，例如“2026年社区茶艺公益培训”。 |
| 项目期次（必填） | 填写项目期次，例如“第一期”；同一项目分几期举办时按实际期次填写。 |
| 项目负责人（自动带出／只读） | 老师本人申报的项目，负责人就是本人，承办学院是本人所在学院，不用另外选择。 |
| 培训类别（单选）（必填） | 按项目实际性质选择培训类别。 |
| 受众群体（必填） | 按本次培训实际面向的人群勾选，可以多选；没有合适选项时在“其他”里补充。可选：企业职工、社区居民、退役军人、新型职业农民、中小学教师、机关事业单位人员、待业及转岗人员、老年学员。 |
| 其他受众群体（选填） | 上面的选项都不合适时，在这里补充其他培训对象；没有可以不填。最多 200 字。 |
| 服务面向类型（必填） | 按项目实际服务方向勾选，可以多选，相关依据在培训方案里说明。可选：国家战略、区域发展、行业发展、其他。 |
| 高风险项目（选填） | 项目涉及高空、水上、用电、外出等高风险活动时勾选，并落实对应的审批和安全措施。 |
| 项目封面（选填） | 可以上传一张项目展示图片，只用于列表展示，不能代替证明材料。支持 PNG、JPG，单个不超过 5MB，只能上传 1 份。 |
| 项目方案材料（可一次选多份）（选填） | 上传培训方案等项目材料。现在可以先不传，保存后在详情里补；提交审核前至少要有一份。支持 PDF、PNG、JPG，单个不超过 10MB，可以一次选多个文件，最多 50 份（含已上传的）。 |
| 开始日期（必填） | 填写实际开始日期。 |
| 结束日期（必填） | 填写实际结束日期，不能早于开始日期。 |
| 预计收入（元，公益类填0）（必填） | 填写培训方案里的预计收入，单位为元；公益类项目填 0。结项时另填实际到账收入。示例：0 或 30000。不能填负数，最多保留两位小数。 |
| 预计人次（必填） | 填写方案预计的培训人次；结项时再核对实际人次。示例：120。不能填负数，只能填整数。 |
| 预期成果（必填） | 写清培训结束后学员能掌握什么技能、项目预计取得什么成果，以及怎样核验；不要只写“完成培训”。示例：学员掌握基础茶艺，80%以上取得结业证书。最多 200 字。 |
| “一人一技”专项（选填） | 属于“一人一技”专项培训行动时勾选，勾选后要填写重点群体与行动对接。 |
| 是否需要报省（选填） | 按上级和学校要求选择是否需要报省；选“需要”时要在下面写明依据。 |
| 报省要求与依据（选填） | 选择“需要报省”时必填：写明省级专项文件、报送口径或学校要求。示例：湘人社〔2026〕12号文，须在结项后15个工作日内报送。最多 2000 字。 |
| 重点群体与行动对接（选填） | 勾选“一人一技”专项时必填：写清面向哪些重点群体、怎样对接行动，例如“脱贫人口、返乡青年；结业后推荐就业”。示例：脱贫人口、退役军人；对接“一人一技”行动。最多 1000 字。 |
| 总学时（选填） | 填写项目的总学时；草稿可以先空着，提交学院审批前必须填。示例：32。不能填负数，可以填 0.5 学时这样的半学时。 |
| 视频资源总时长（分钟）（选填） | 填写项目建设的视频资源合计时长，单位是分钟；没有填 0。示例：199。不能填负数，只能填整数。 |
| 实践教学基地数量（个）（选填） | 填写项目使用的实践教学基地数量；没有填 0。示例：2。不能填负数，只能填整数。 |
| 教学实施方式（必填） | 按实际采用的教学方式勾选，可以多选，与培训方案一致。可选：课堂教学、案例教学、现场教学、实地考察、交流研讨、实验实训、岗位实习、学习者互助、其他。 |
| 培训场地（必填） | 按实际上课地点选择校内培训基地、其他校内场所或校外；选校外要另外说明理由。 |
| 具体地点（基地名称、楼宇教室或外出地点）（必填） | 填写能找得到的具体地点，例如基地名称、楼栋教室或校外详细地址。 |
| 校外培训的外出理由（一事一议）（选填） | 培训场地选“校外”时必填：说明为什么不能在校内开展。示例：茶叶采摘与制作必须在茶园现场教学，校内没有条件。最多 1000 字。 |
| 议定文号或会议日期（选填） | 培训场地选“校外”时必填：填写学校一事一议的会议日期或文号。示例：校长办公会 2026-08-20 或 校办〔2026〕15号。 |
| 核算方式（单选）（必填） | 按学校确认的计分方式选择模块式或人天式，与项目实际组织方式一致。 |
| 标准班类型（单选）（必填） | 按项目实际内容选择技术类、讲座类等标准班类型；这一项影响积分计算。 |
| 项目层级（单选）（必填） | 按认定依据选择项目层级：企业定制通常选市级，社区、免费帮扶通常选校级；不要自行提高等级。 |
| 授课场景（单选）（必填） | 按实际情况选择是否异地送教、全天实操或脱产培训，并保留相应依据。 |
| 专项层级认定依据（选填） | 项目层级高于常规时必填：填写正式认定文件名称和文号，提交后由归口核验。示例：省人社厅专项培训认定文件〔2026〕8号。最多 1000 字。 |
| 随项目备案的辅助积分细则（选填） | 写明随项目备案的辅助工作积分细则：哪些工作、每天多少分、依据是什么。示例：班主任每天0.5分，每人每天不超过1分。 |

## 课程认定积分

1. 老师申请后课才会出现在这里。打开“待我办理”，在左侧选一位老师，右侧每门课一张卡片。

2. 展开“课程内容与认定条件”核对课程；看“办理记录”里前面各级谁通过、积分怎么改、意见是什么。

完成标志：学校认定后积分记入老师个人积分，课程进入老师的培训课程库；学分学时在源头变化后会从教研室重新审核。

## 常见问题

### 项目备案后中途要改内容怎么办（申请变更）

打开项目，点“项目运行”进入运行档案，再点“申请变更”，只勾要改的项（延期、换负责人、预估人次、预计收入、场地等）。小变动直接生效并留痕，一般变动由学院审批，核心变动学院审批后报学校备案。审批期间项目照常运行；通过后生成新版本，改前改后都能查。预估人次、预计收入是和上次审批通过时的值比，连续小改动会累计。

### 项目、课程、基地、师资的运行过程怎么记

在对应的详情里点“项目运行 / 课程运行 / 基地运行 / 师资运行”：点“记一笔”随手记开班、加课、检查、整改，不用审批；可以补传运行材料；基地、师资每年做一次“年度确认”。运行档案里的时间线会标明每一笔是本人、学院、学校还是系统自动记的。

### 课程、基地、师资暂时不用了怎么办（停用与恢复）

在运行档案里点“停用”并写原因。停用不是作废，历史数据和已开过的课都保留，已有的课程积分照常办理；停用的课程不能再导入新的参训明细，需要时点“恢复运行”。有变更正在审批时要先撤回变更再停用。

### 为什么立项时总学时、受众这几项可以先不填

立项只要求能判断项目的基本信息；总学时、受众群体、服务面向类型、教学实施方式可以先空着，项目负责人在备案后、结项前补齐即可，结项提交时系统会再检查一次。

### 找不到按钮或菜单

先看右上角的当前身份：兼任负责人的老师，办审核要切换到负责人身份，办本人申报要切回教师身份。菜单只显示当前身份有权限的项目；切换后还是没有，请学校管理员核对你的账号和角色，不要借用别人的账号。

### 提交后在哪里看进度

点左侧“工作台 → 待办中心”，选“我的申请”；或者在首页点“我的申请”。打开申请就能看到现在在哪个环节、由谁办理，以及每一步的办理记录。

### 积分为什么还没到账

积分要走完“院长初审 → 归口复审 → 分管副校长审批 → 教学秘书归档”，归档后才进入个人台账。只是审批通过、还没归档时不会显示到账。另外，培训课程入库本身不产生积分，积分按你在培训项目里的授课人次认定。

### 附件传不上去（材料上传失败）

先看文件格式和大小：一般支持 PDF、PNG、JPG，单个不超过 10MB（封面图片不超过 5MB）。文件太大可以压缩或分成几份；文件名里不要有特殊符号。每份文件单独显示上传结果，只需补传失败的那一份，已经成功的不用重传。

### 申请被退回了怎么办

打开原申请看退回意见，点“补正资料”只改指出的问题，原来正确的内容和附件保留；保存后一定要点“重新提交”。不要另外新建一份。

### 保存了为什么没有提交

“保存草稿”和“提交”是两个动作。保存草稿只是自己留着，审核人看不到；要点“提交”或“重新提交”才会送到下一环节。

### 同一级有几位负责人，要每个人都审批吗

不用。同一组织可以设几位负责人，任何一位办理后这一环节就完成了，其他负责人在“已办”里能看到是谁办的。

### 为什么不能审核自己的申请，或者由上级代办

本人的事项必须回避，由同组织其他负责人办理；教研室、学院没有其他能办的负责人时，系统交给上一级代办。学校级职责缺人时需要管理员配置，不能跳过。以申请详情里显示的办理人为准。

### 超星课程没有显示

“我的超星课”只显示你作为建课人的课程。超星账号用的不是本名或工号时，到“授课学分 → 超星课程”点“认领我的超星课程”，只填超星登录名，不需要超星密码。姓名一致也需学校管理员核对建课人身份，确认后才生效。

### 没有审批人员，事项卡住了

看申请详情里的当前环节。学校环节没人办，是对应审批职责还没配人，请联系学校管理员在“用户与权限 → 学校审批职责”里给对应职责添加办理人，不要重复提交。

### 表单填到一半想离开

可以先“保存草稿”。离开前系统会提醒未保存的内容；附件在保存前没有上传，回来后可能需要重新选择。打开帮助不会离开表单，也不会清掉已填内容。

### 数据为空或和我知道的不一样

先核对统计周期、组织、身份和筛选条件。缺少来源数据或还没认定，不等于零；确实有疑问，从那条记录进入“数据核对”提出。

### 批量操作只有一部分成功

逐条看结果和原因，只重新办理失败的那几条，不要把点过批量按钮当成全部成功。
