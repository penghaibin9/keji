# 一站式非学历教育智慧前台：前端与业务办理改造总结报告

日期：2026年10月9日至10日
范围：本窗口共做了三轮改造，起因是“核对系统有没有吃透招标文件，特别是不同角色看到的页面”。三轮代码都已写进 D 盘项目，打包线程也已据此重新打了服务器更新包。

---

## 一、一句话结论

- 菜单结构、四级角色、主要业务流程，总体上都符合招标文件和验收老师的手写菜单。
- 问题主要有三类：
  - **看到了不该看的**：越权；
  - **看到了用不了的**：按钮点了就报错；
  - **办起来不顺**：办完一步被踢回列表、要反复手打意见、被拦了才知道缺什么。
- 三轮下来，这三类问题都改了，另外按你的要求新增了“教研室发现积分不对”的核对流程。
- 最后把三轮改动整体复核了一遍，又修了 15 处。

## 二、三轮分别做了什么

### 第一轮：对照招标，理清各角色该看到什么

**越权与“看得到用不了”（共 7 处）**

| 问题 | 改成 |
|---|---|
| 教师能打开“学院台账与口径检查”，看到全院老师的人次分配（违反招标第2项“教师仅访问本人数据”） | 对教师隐藏，服务器也拒绝 |
| 教研室负责人能看整院台账，还能看到点了会失败的“上传学院统计表” | 教研室只保留“教研室平均积分”，只看本室 |
| 教研室负责人首页显示的是整个学院的数据，标题写着“本学院核心指标” | 改为本教研室的人次、收入、双师型人数 |
| 教研室负责人进项目、课程、基地、成果四页全是空的，却有“申报”等按钮 | 能只读查看本室教师负责或参与的项目、相关课程，按钮去掉（招标第6项） |
| 培训课程不分角色，教师能看全校课程 | 教师只看本人相关的，教研室只看本室相关的 |
| 教师项目详情有“上传佐证”，但没权限 | 去掉 |
| 教师菜单叫“表格导入导出”，其实只能导出 | 改叫“导出下载” |

**办理体验**
- 教师申报资质从三步改为一步：填信息、传证书图片、直接提交。这是按老师手稿“自己申报图片”改的。
- 项目申报表单：
  - “教师”改为“项目负责人”；
  - 去掉误导的必填星号；
  - 保存后自动打开项目，并提示下一步做什么。
- 首页“结项到账收入”和驾驶舱“归属培训收入”是两个口径，原来名字一样，容易看混，现在分开命名。

**配套文档**：《核心业务流程_按角色.md》《招标逐条核对_前端与角色页面.md》（14 项逐条核对表）。

### 第二轮：按角色把业务真正走一遍，卡手的地方都改

用教师、教研室、学院、学校管理员、归口复核人、分管副校长 6 个账号，把 7 条主线从头走到尾：项目、制度口径、积分申报审批、资质、数据核对、考核规则、三级考核。

改了这些：
1. **办完一步不再被踢回列表**：自动回到这条记录的详情，表单里的“取消”变成“返回详情”。
2. **常规操作不用手打意见**：
   - 提交、通过、归档这类操作，意见栏已预填好；
   - 退回、解锁这类操作仍要本人写原因；
   - 按钮名字也改具体了，比如“确认并提交学院”。
3. **会被拦下的情况提前说**：没传佐证、申报有拦截项、审批到了本人头上、编号重复等，都在办理前直接提示，不再点了才报错。
4. **学院项目全流程**：
   - 培训类别必须先选；
   - 项目详情里可以直接登记课程；
   - 导入参训明细有模板，能选 CSV 或从 Excel 粘贴，日期写法更宽松；
   - 结项表单分块显示，无关栏目自动隐藏，比例自动算并用颜色提示，材料可一键全勾。
5. **学校**：“制度口径”“年度考核”做成正规页签；文号、校历在登记时就校验；新建规则自动起名，保存后直接打开。
6. **教师**：
   - 积分页分成两个页签；
   - 项目下拉框只列本人能申报的项目；
   - 辅助工作原来要用 Tab 分隔，实际填不进去，现在改成逐行填写；
   - 积分流水每行加了“有异议”按钮。
7. **修了两个显示问题**：右侧提示框被拉成整屏长条；打开几类详情时出错。

**配套文档**：《第二轮_业务办理顺畅度修改.md》。

### 第三轮：教研室发现教师积分不对怎么办 + 整体复核

**新流程：积分核对**

| 积分走到哪一步 | 怎么办 |
|---|---|
| 还在审批中 | 审批人直接“退回补正” |
| 已经归档入账 | 教研室或学院发起“积分核对”，上传材料后发给教师 |
| 正在做考核 | 核对没办完，考核就不能确认、不能归档，页面会写明原因 |

核对单的走法：
1. 教研室发起，上传材料，发给教师。
2. 教师回应：
   - **同意**：自动生成更正单，走原来的四级审批，只追加差额，原记录不改；
   - **不同意**：写明理由，交学院院长裁定。
3. 院长裁定：
   - **裁定更正**：生成更正单，跳过院长初审；
   - **维持原认定**：核对办结，积分不变。
4. 发起人在教师回应前可以撤回。

防出错的规矩：
- 同一条积分同时只能有一件核对或更正在办，防止重复扣分或加分。
- 由核对生成的更正单不能改分值。
- 发起人回避，不能审批自己发起的更正。
- 教师看不到还没发给他的草稿。

**整体复核**：把三轮的前后端改动又查了一遍，修了 15 处。

| 后端 8 处 | 前端 7 处 |
|---|---|
| 核对期间还能另开更正单，会重复入账 | 教学秘书点不了自己生成的汇总的“归档” |
| 教师一同意考核就放行，但更正还没入账 | “上传佐证”对没权限的人也显示 |
| 退回后能改核对确定的分值 | 已有核对或更正在办时，仍显示“发起核对” |
| 教师能看到核对草稿 | 发给教师前没传材料不提醒 |
| 发起人发出后还能加材料 | 原口径停用后，修改申报会悄悄换口径 |
| 院长裁定后还要自己再初审 | “返回详情”失败时没有任何提示 |
| 教研室负责人看项目列表时重复读数据，较慢 | 考核被核对挡住时，仍显示“本人确认”，点了才报错 |
| 重复登记的提示可能说错原因 | |

**配套文档**：《第三轮_教研室积分核对与整体复核.md》。

## 五、还需要学校或你来定的事

1. **部署**：最新服务器更新包已在 D 盘，部署时只用最新那一个。
2. **教学秘书至少配两个人**：装好后，学校管理员在“社会培训职责设置”里配。发起核对的人要回避，只配一人的话，他发起的更正最后没人能归档。
3. **培训收入口径**：首页用“结项到账收入”，驾驶舱用“归属培训收入”，现在只是分开命名，没有合并。招标第 7.5 条要求同一指标只能有一套数，建议请继续教育学院定正式对外用哪个。
4. **教研室能不能申报项目**：按管理办法“以二级学院为主”，现在教研室只读。如需教研室也能申报，要另加权限。
5. **外部对接**：
   - 统一认证还没和学校真联调；
   - 数据中台缺接口文档；
   - 湘培直通车缺省平台接口；
   - 100 并发、3 秒响应要在学校服务器上实测。

   这些系统侧都已做好适配，等外部条件到位。
