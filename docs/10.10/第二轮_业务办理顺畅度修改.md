# 第二轮：分角色把业务真正走一遍，卡手的地方都改了

做法：在测试环境里用教师、教研室负责人、学院负责人、学校管理员、归口复核人、分管副校长这几个账号，像真人一样点页面，把下面几条主线从头走到尾。凡是走不下去、要猜、要来回找的地方，当场改掉再重走，直到顺畅为止。

## 走通的业务主线

| 主线 | 经手角色 | 结果 |
|---|---|---|
| 培训项目：申报 → 上传材料 → 提交 → 审核备案 → 登记课程 → 导入参训明细 → 结项 → 结项核验 | 学院、学校归口 | 全程走通 |
| 学校积分口径：新建 → 登记书面文号 → 上传依据 → 换人启用 | 学校管理员、归口复核人 | 全程走通 |
| 教师积分：本人申报 → 院长初审 → 归口复审 → 分管副校长审批 → 教学秘书归档 → 教师确认 | 教师及四级审批人 | 全程走通，积分已入账 |
| 教师资质：教师一次提交 → 教研室审核通过 | 教师、教研室 | 全程走通 |
| 数据核对：教师对积分提出异议 → 教研室复核 | 教师、教研室 | 全程走通 |
| 考核规则：新建 → 试算 → 启用 | 学校 | 全程走通 |
| 三级考核：生成 → 教师确认 → 教研室 → 学院 → 学校审核 → 归档 | 四级 | 全程走通 |

## 改了哪些卡手的地方

### 1. 办完一步不再被“踢回列表”
- 以前：上传材料、提交、审核、修改之后，窗口一关就回到列表，还得重新找到这条记录、再点开。
- 现在：每办完一步，自动回到这条记录的详情。
- 表单里的“取消”改成了“返回详情”。

### 2. 常规操作不用每次手打意见
- 提交、审核通过、确认、归档、启用这类常规操作，意见栏已经预填了一句话，可以直接点，也可以改。
- 退回、解锁、停用这类操作仍然必须本人写原因。退回的输入框会写明“对方会看到，写清要补什么”。
- 按钮名字改得更具体：
  - 不再出现“确认确认……”这样的重复字；
  - “确认并提交下一级”改成了“确认并提交学院”“审核通过，进入归档”等。

### 3. 会被系统拦下的情况，提前告诉你
- **还没上传佐证材料：** 提交或启用时，表单顶部直接提醒先上传，详情里的“上传佐证”按钮也会高亮。
- **积分申报有拦截项：** 比如校历没确认、超过申报期限，提交前就把原因列出来。
- **审批到了本人的事项：** 不再显示一个点了就报“须回避”的按钮，而是直接说明须由其他人审核。
- **常见的重复登记**（证书编号、项目编号、单元编号、课程编号）：报错不再是看不懂的“数据重复或关联关系冲突”，而是告诉你哪里重复、该怎么办。

### 4. 学院：项目申报到结项
- **申报项目：** “培训类别”原来默认是“补贴性培训”，不改就保存失败。现在要求先选类别；选了补贴性培训，“重点群体与行动对接”会自动变成必填并给出提示。
- **项目详情：** 新增“登记本项目课程”按钮，不用再跑到别的页面登记课程。
- **导入参训明细：**
  - 新增“下载导入模板”，可以直接选择填好的 CSV 文件，也可以从 Excel 复制粘贴；
  - 表单会列出本项目已登记的课程编号；还没登记课程时，会直接告诉你先去登记；
  - 日期写成 2026/9/10 也能识别。
- **结项表单：**
  - 分成“结项情况、经费与财务核验、补贴专项材料、整改、材料核对”几块；
  - 不相关的栏目自动隐藏：非补贴项目不显示专项材料，满意度不低于 85% 不显示整改，非政府专项不显示专项依据；
  - 输入到账收入、留存、人员支出后，自动算比例，并用颜色提示是否符合要求；
  - 新增“以下材料全部已核对”一键勾选。

### 5. 学校：口径、规则、考核
- **页签：** “社会培训制度口径”和“学院社会培训年度考核”原来是挂在页面顶上的两个散按钮。现在和“考核周期与规则”“三级考核”一样，做成了正规页签。
- **登记制度口径：**
  - 登记学校书面依据时，“文号”栏变成必填，并写清楚要填什么；
  - 校历要求三项一起填（开始日期、结束日期、校历依据），缺一项就当场提示，不再等到教师申报时才报“学校工作日历尚未确认”；
  - 放假日期、补班日期填错时，会指出是第几个日期写错了。
- **新建规则：** 自动起名（如“2026 周期 三级考核规则”）。保存后直接打开规则详情，可以马上试算、启用。

### 6. 教师：积分、资质、核对
- **页签：** “教师积分激励”页顶部改成两个页签：“积分核对与确认”和“社会培训积分申报与认定”。教师还会看到一个醒目的“去申报本人积分”按钮。
- **积分申报：**
  - 项目下拉框只列出“已结项、且参训明细里有本人工号”的项目；没有可申报项目时，会说明原因；
  - 辅助工作原来要在一个文本框里用 Tab 键分隔填写（实际上按 Tab 会跳到下一个输入框，根本填不进去）。现在改成逐行填写日期、积分、说明，可以加行、删行；
  - 只列出已启用的口径。
- **数据核对：**
  - 积分流水每一行加了“有异议”按钮；
  - 教师打开“数据核对与复核”页时，会看到“怎么提出核对”的说明。
- 资质页的提示改成了一次提交的新流程说明。

### 7. 修掉的两个问题
- **右侧提示框显示问题：** 提示框会被拉成从上到下的整屏深色长条，挡住页面右侧。已修好。
- **打开详情出错：** 打开数据核对详情时，复核按钮会带上错误参数，详情里还会多出一个不该有的“返回考核并刷新”按钮。导入任务、对接收件详情也有同类问题。已修好。
