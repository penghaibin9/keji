# 管理员操作手册

## 1. 首次初始化原则

生产首次安装必须先完成真实迁移链，再显式运行空校初始化；程序启动不得自动建表、自动生成演示业务数据或重置正式库。初始化会建立一个学校根组织、教师/教研室/学院/学校四类基础角色、学校管理员、计算保护记录、基础参数与字典，以及统一认证/学校数据中台/湘培直通车三类接口登记。三类接口初始状态均为 `NOT_CONNECTED`。

管理员临时密码从独立 secret 文件读取，不写进镜像、源码或业务审计。管理员首次登录必须自行改密。

## 2. 组织、账号与权限

组织层级为学校 → 二级学院 → 教研室。教师和教研室角色绑定教研室，学院负责人绑定学院，学校管理角色绑定学校根组织。角色支持批量授权与复制；数据范围由角色层级与当前组织关系动态计算，不逐用户复制数据范围。

组织或角色变化后，应立即验证旧会话、旧导出和旧下载是否失效。系统服务端执行范围校验，不能以隐藏菜单作为安全控制。

## 3. 基础配置与字典

可维护学校品牌、资质类别和到期提醒、统计口径说明、业务字典/状态显示、Excel 单批最大行数等受控参数。流程状态码和合法状态流转由服务端固定约束，管理员只能修改允许的显示名称，不能用配置把已归档状态改成可写状态。

关键配置变更必须填写原因，配置详情可查看操作人、时间、调整前值、调整后值和原因。

## 4. 周期、积分和考核规则

新周期建立后，规则按版本保存。修改既有制度时复制形成新版本，先选择代表教师/组织执行试算，确认后再启用。启用新版本不重写历史已确认积分或已归档考核。

学校真实上线前，必须使用 `acceptance/学校真实样本双轨比对模板.xlsx` 记录学校代表性真实样本，并通过 `scripts/dual_track_acceptance.py` 验证积分和考核人工/系统结果均达到 100% 一致，再由学校人员签认。

## 5. 接口配置

“配置完成”与“连接成功”严格区分。管理员可维护 HTTPS 地址、责任单位、鉴权模式、密钥环境变量名称、重试次数、同步频率和按数据类型的字段映射。页面不接收真实密钥值。

字段映射可以使用脱敏样本做本地转换验证；本地验证不会访问外部网络。学校数据中台还支持入站预览 → 错误定位 → 明确确认 → 正式主数据，以及 FULL 全量、INCREMENTAL 增量、人工拉取和定时计划的内部执行链。定时计划只有在真实 `CONNECTED`、已注册真实拉取适配器且管理员明确批准自动确认入库时才能启用；批准人失效、降权或接口掉线会自动停用计划。真实接口协议、网络和凭据未完成前连接状态必须保持 `NOT_CONNECTED`。

## 6. 统一待办与审计

统一待办覆盖资质审核/到期、教师考核、组织考核、核对申请和同步异常。办理后应检查待办是否随业务状态关闭或转交下一责任层级。

审计中心用于追查登录、配置、权限、资质、积分、考核、同步、导入导出等操作。关键业务审计与业务事务绑定；普通访问日志存储失败不得反转已经成功提交的业务响应。

## 7. 日常运维观察

运维页面只显示真实检查结果，不把采购阈值显示成“已通过”。每天关注数据库状态、worker 心跳、磁盘空间、最近备份和失败任务。备份文件存在不等于可恢复，必须定期在独立空实例做恢复演练。
