# 教师端逐页精修与视觉核验

日期：2026-10-19。最终结果：通过本轮范围内的检查。当前产品源码和既有设计语言为视觉目标，不使用已撤回的重新设计方案。此次保持当前菜单、页面骨架、权限、审批流程和数据口径，做小范围可读性和操作细节修正。

## 本轮发现与修复

1. [中等] 表格、状态和说明小字较多。表格正文统一为15像素、表头14像素、主要名称16像素；标签13至14像素，补充说明14像素。次要文字用更深的颜色，层级通过字重和间距区分。
2. [中等] 通知、资质的查询按钮与输入框相隔约765像素。限制关键词容器伸展后，桌面间隔约14像素；手机自动换行，按钮仍在输入框旁的操作区。
3. [中等] 申请汇总中有已办结计数，缺少对应筛选。补上已办结筛选，沿用服务端现有绿色进度口径，与后台counts.done一致；已生效基地或已备案项目不能仅凭底层状态枚举误判。回归覆盖和手机实页筛选均通过。
4. [中等] 通用“查看”按钮用途不明确。按已有进度说明为“查看进度”或“查看详情”，个人项目入口为“查看项目”；动作仍指向原详情，补正逻辑不变。同步扩宽申请和个人表格的操作列至140像素，避免新文案被裁切。
5. [中等] 课程详情的长学期值使两列行高不齐。调整标签和值的列宽后，桌面学期正常显示在一行；手机采用单列信息行，提示和底部操作保留。
6. [中等] 手机课程卡片原120像素固定高度会裁掉内容。初次改为自动高度后，网格仍会压缩卡片，第二次设置自然网格行高。最终卡片可视高度与内容高度均约190像素，文字和“查看详情”完整呈现，列表自身可滚动。
7. [轻微] 四类申报说明、空态和表单提示字号、间距不一致。统一提示、按钮和焦点样式；课程申报优先突出“从我的课程导入”，手填入口继续保留。

## 五项视觉复核

- 字体与层级：沿用微软雅黑和现有字体回退；调整正文、主要名称、状态、提示字号，保留页面和卡片标题层级。课程详情的学期换行及申请长按钮均通过最终局部对照检查。
- 间距与布局：保留原有顶部抬头、侧栏、工作台双栏和页面顺序。检索按钮靠近字段；表格操作列、表单固定页脚、手机自然卡片高度已检查。
- 颜色与状态：保留系统蓝色及原有语义色。次要说明使用更深颜色；未改变审批状态、认定规则或计分口径。
- 图片与图标：继续使用学校校徽和已有图标资源，没有重新生成或近似绘制学校标识。
- 文案与业务：操作文字明确用途；已办结筛选复用服务端口径；数据、进度和办理人均来自隔离库接口，未将设计示例写入日常数据库。
