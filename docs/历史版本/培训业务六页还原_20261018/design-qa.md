# 培训业务六页视觉与交互核对

final result: passed

核对范围：日常系统当前可用数据状态、真实空状态、主要查看入口与响应式布局。此结果不等于效果图示例内容逐像素一致，也不表示基地与师资库的非空业务状态已在浏览器验证。

## 参考与实现

参考为用户指定生成目录内六张原图：项目、课程、基地、师资、数据、成果。实际实现为 http://localhost:8773/ 的原有六条业务路由。桌面比较视口1672×941，手机视口390×844。参考图与对应实现截图已成对放入同一视觉比较输入，未将代码检查代替视觉检查。

实际页面使用日常测试数据及“隔离测试学校”配置，因此学校抬头、记录标题、数量、日期、业务状态与效果图中的演示内容不同。正式学校标识仍按原配置机制显示。既有导航及权限保留，未为了截图新增业务记录。

## 首轮发现与修正

- 详情面板主操作可能在屏幕底部被截断：调整详情滚动区及底部固定操作，复查按钮底部均在941像素视口内。
- 培训数据“更多筛选”被旧布局定位到筛选框外：恢复到新筛选表单内部。
- 新列表与旧分页同时显示总数：保留单一服务端分页说明。
- 未关联项目的已入库课程缺少已有学院信息：接口返回已授权课程的所属学院，前端据此展示及筛选，权限回归通过。
- 未知基地类型不能推断为校内；零学时不能显示为缺失；仅基础信息的师资不能出现详情办理入口：已保留并有回归检查。
- 手机选中项目或课程后详情在清单末尾：选中后聚焦并滚动到详情区。
