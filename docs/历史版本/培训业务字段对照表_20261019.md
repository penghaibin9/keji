# 培训业务字段对照表（项目、课程库、基地、培训师）

依据：《六类培训业务统一整改计划》第二节字段清单；2026-10-19 在代码和浏览器里逐项核对。
状态：**有** = 表单可填、保存、详情和列表显示；**部分** = 有但缺某个入口；**未做** = 没有，原因见备注。

## 培训项目
| 规划字段 | 状态 | 位置 / 备注 |
|---|---|---|
| 编号、期次、学院、负责人、培训类别、培训期间、核算依据 | 有 | 申报表、详情、列表 |
| 项目级“一人一技”标记 | 有（10-19 新增） | 申报表勾选；勾选后重点群体必填 |
| 重点群体与行动对接 | 有 | 补贴类或一人一技必填 |
| 是否需要报省、报省要求与依据 | 有（10-19 新增） | 勾选后依据必填 |
| 预计人次、预计收入 | 有 | 申报表；详情在结项前显示 |
| 有效人次、到账收入（实际） | 有 | 结项后详情自动显示 |
| 总学时 | 有 | 申报表、详情 |
| 封面（选填） | 有（10-19 新增） | 申报表上传；详情可更换、移除 |
| 课程数量、项目材料数 | 有 | 详情 |

## 培训课程（课程库）
| 规划字段 | 状态 | 位置 / 备注 |
|---|---|---|
| 编号、名称、简介、面向对象、学时、教学方式、思政属性、主讲教师 | 有 | 申报表；课程库详情（10-19 补显示面向对象、思政属性、简介、课程编号） |
| 关联项目 | 有 | 详情 |
| 培训包、“一人一技”（含重点群体与行动对接） | 有 | 申报表；课程库详情（10-19 补显示） |
| 视频、文档、链接分类资源 | 有 | 课程资源页 |
| 封面（选填） | 有（10-19 新增） | 课程申报表上传；申请详情可更换 |
| 四类主题（育训融合等） | **不做** | 用户 10-18 决定取消 |
| 入库后资料维护入口 | **未做** | 招标未要求，按“不扩大”不做 |

## 培训基地
| 规划字段 | 状态 | 位置 / 备注 |
|---|---|---|
| 编号、名称、学院、用途、级别、地点、校内／校外、共建单位、设立日期、认定依据 | 有 | 申请表、学校登记表、详情；修改时不再丢字段（10-18 修复） |
| 基地负责人 | 有（10-19 新增） | 申请表、登记表、详情 |
| 认定日期（与设立日期、审批生效日期分开） | 有（10-19 新增） | 申请表、登记表、详情同时显示设立、认定、审批生效三个日期 |
| 封面、场地照片（选填，照片最多 6 张） | 有 | 申请表和登记表可传封面；场地照片在详情里添加 |
| 项目校外用地“一事一议” | 有 | 项目申报表的培训场地 |

## 培训师资
| 规划字段 | 状态 | 位置 / 备注 |
|---|---|---|
| 编号、单位、职称、认定／备案依据、日期 | 有 | 申报表、师资库详情 |

| 省级推荐记录 | 有 | 师资库详情 |
