# 在账号里直接配置学校审批职责（2026-11-04）

## 起因
学校审核人（test）设了“学校业务审核”兼任身份，项目 111 学院审批后到了学校一级，却没进他的待办。
原因是配置：学校一级只按“社会培训职责”（setting social_training_duties）里“归口学院复审”的名单派单，
服务器上这份名单从没配过，所以谁都收不到。入口在“规则配置 › 社会培训制度口径 › 配置审批职责”，不好找。

## 改动（审批规则本身不变：职责走、本人回避、同一职责任何一位办理即生效）
- 账号管理“调整账号”里新增“学校审批职责”勾选区。有“学校业务审核”这类学校审核身份才能勾；
  新添加该身份时默认勾“归口学院复审”；职责和账号一起保存、一起审计，保存失败整体回滚。
- PUT /api/users/{id} 新增可选字段 school_duties（不传不改，传空表示不再担任）；只改这个人在各职责里的进出，其他人不动。
- GET /api/users 返回每个账号的 school_duties、duty_labels、duty_staffing；账号列表新增“学校审批职责”列，
  归口学院复审缺人或只有 1 人时列表顶部提醒。
- 学校系统管理员首页新增“学校审批环节缺少办理人”提醒（/api/portal/workbench 的 duty_alerts，仅学校系统管理员可见）。
- 帮助内容改为先讲账号里的配法；规则配置页原来的“配置审批职责”保留，两处改的是同一份数据。
- 前端版本号 20261104-duty1。没有数据库迁移，没有改设置字典。

## 测试

- 前端 597 项全过；本地浏览器走通：添加兼任身份后自动勾“归口学院复审”，管理员首页出现提醒。
