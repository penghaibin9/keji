# 六类培训业务整改：设计与进度

日期：2026-10-18。分支：`claude/training-six-pages-20261018`（只在本地提交，没有推送，也没有合并）。

## 一、已定的口径（你 10/18 确认）
- 四类课程主题（育训融合、智慧助老、学习型社区、乡村振兴）不做。课程页只保留“培训包”“一人一技”两个勾选筛选，原来重复的页签去掉。
- 满意度恰好 95% 计为 C 等成果。系统推荐口径改成“可以认定成果”。**已经在使用的制度口径不会自动改**，需要学校管理员在“执行口径”里改一次，这样会留下记录。

## 二、图片字段设计（已实现）

| 业务 | 图片 | 数量 | 谁能维护 |
|---|---|---|---|
| 培训项目 | 封面 | 1 张 | 项目负责人、所属学院或学校的登记人员 |
| 培训课程 | 封面（存在课程资料记录上） | 1 张 | 课程申请人、所属学院或学校 |
| 培训基地 | 封面和场地照片 | 封面 1 张，照片最多 6 张 | 申请人、所属学院或学校 |
| 培训成果 | 封面 | 1 张 | 所属学院或学校 |
| 培训师资 | 头像 | 1 张 | 培训师本人、所属学院或学校 |

规则：
- 图片都是选填，只接收 PNG 或 JPG 格式，单张不超过 5MB。系统沿用现有附件的格式校验，伪装成图片的文件、超大图会被拒绝。
- 图片和证明材料**分开存放**：图片不出现在“材料”里，也不能满足“须先上传佐证附件”的提交检查。
- 更换或移除图片只改当前显示的那一张，原图保留，办理记录里会留一条“更换封面”或“移除场地照片”，审批状态不变。
- 能在列表里看到这条记录的人就能看到图片；证明材料仍按原来的权限下载。
- 修改项目资料、申请补正以后，图片引用都会保留。
- 没有图片时显示业务类型图标和“暂无封面”，不再用生成的示意照片。

接口：
- `POST /api/social/images/{project|resource}/{编号}`：上传图片，用途分为封面 cover 和场地照片 photo。
- `POST .../remove`：移除当前显示的图片。
- `GET /api/social/images/{图片编号}`：在页面里直接显示图片。

## 三、审计问题处理情况

| 编号 | 问题 | 状态 |
|---|---|---|
| A1 | 修改基地或成果时清空了没提交的字段 | 已修。后端只合并提交了的字段；修改表单补上用途、级别、设立日期、共建单位；校外基地必须填共建单位；基地级别和成果等级分开校验 |
| A2 | 老师申请入库的基地显示“修改资料”按钮，一点就报错 | 已修，不再显示这个按钮。入库后的资料维护走计划第四步 |
| A3 | 图文页面套给了四个角色 | 已修。图文工作台只给学校身份用，教师、教研室、学院恢复原来的清单 |
| A4 | 项目指标不分阶段，结项后仍只显示预计数 | 已修。结项以后显示有效人次（扣除作废期次）和到账收入；补上课程门数和“项目材料 · N 份”入口；主按钮按阶段显示，比如“办理备案”“办理结项核验” |
| A5 | 已结项进度条仍显示进行中；待审批里混进了草稿 | 已修 |
| A6 | 封面用的是生成的示意图 | 已修，改成显示图标 |
| A7 | 结项退回在各处状态不一致 | 已修，列表也显示“结项退回补正” |
| A8 | 审批时补录课件审查会覆盖已有记录 | 已修，已有审查记录时后端拒绝覆盖 |
| A9 | 筛选只在当前页执行，翻页按钮会消失 | 部分修。学院筛选改成按学院编号；设置筛选后保留翻页，并提示“筛选仅作用于当前页”。每页 200 条，**服务端筛选还没做** |
| A10 | 其他小问题 | 已修：课程页签重复、师资状态写死、组织缺失会报错 |

## 四、下一步（还没做）
1. 课程、基地、师资的草稿流程。必须用一个新状态，不能用 DRAFT，因为通过审批的基地存的就是 DRAFT。
2. 入库后的资料维护和更正入口，审计里的 A2 已经指出这个缺口。
3. 双月报送记录“学院主要负责人签字确认”的依据，也就是签字件。
4. 成果的类型、简介、关联项目；基地负责人。
5. 学院和状态筛选改到服务端执行（A9）。
6. 其余要等学校确认的：考核结果分三等还是四等、成果加分怎么合并、年度收入按到账还是按结项、制式表格。
