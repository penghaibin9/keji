# 一站式非学历教育智慧前台：核心业务流程（按角色）

整理日期：2026年10月9日。依据：招标采购清单14项、学校三份制度（管理办法、积分办法、年度考核细则）、验收老师手写菜单，以及系统现有代码。

## 一、系统里有哪四种人

| 角色 | 典型人员 | 能看到的数据 | 一句话说清楚他在系统里干什么 |
| --- | --- | --- | --- |
| 普通教师 | 授课老师、项目负责人 | 只有本人 | 看自己的培训、收入、积分、考核；申报资质和积分；确认考核；有异议就提核对 |
| 教研室负责人 | 教研室主任 | 本教研室教师 | 审核本室教师资质；考核“教研室确认”；看本室教师参与的项目（只读） |
| 二级学院 | 院长、学院经办人 | 本学院及下属教研室 | 申报培训项目、登记课程/基地/成果、报送学院台账；考核“学院确认”；积分“院长初审” |
| 学校管理部门 | 继续教育学院、系统管理员、分管校领导 | 全校 | 项目备案和结项核验、台账核定、下达目标、配置规则、算积分、考核审核归档、看驾驶舱、管系统 |

登录后菜单按身份自动出现，没有角色切换。数据范围由服务器按组织关系判断，换了组织或角色，看到的数据跟着变。

| --- | --- | --- | --- | --- |
| 工作总览 | 工作总览、**个人培训**（登录直接打开）、统一待办、政策通知 | 工作总览、统一待办、政策通知 | 同左 | 同左 |

## 三、六条主线流程

### 1. 培训项目：申报 → 备案 → 实施 → 结项

1. **二级学院**点“申报培训项目”，填项目编号、名称、期次、项目负责人、培训类别、起止日期、预计收入和人次、核算方式（模块式或人天式）等，先存草稿。
2. 系统自动打开这个项目，学院上传申报材料，点“提交审核备案”。
3. **继续教育学院（归口复审人）**审核：一般项目直接备案；补贴项目和高风险项目要登记前置审核日期和依据。不合格就退回补正。
4. 备案后，学院登记课程、导入参训明细（先预检再整批确认，重复编号会被挡住）。
5. 培训结束，学院提交结项材料：结项日期、成果报告、满意度、到账收入、财务凭证等；满意度低于85%要写整改。
6. **继续教育学院**逐项核验8类材料（方案、备案表、名册、签到、学时、过程、考核、成果）后结项。满意度超过95%系统自动登记一项校级成果。
7. **教师**能在项目清单里看到自己负责或授课的项目；**教研室负责人**能只读查看本室教师负责或参与的项目。

### 2. 教师资质：本人申报 → 教研室审核 → 到期提醒

1. **教师**在“教师资质管理”或“个人培训”点“申报我的资质”，填证书信息，上传证书图片，勾选“直接提交审核”，一步完成。
2. **教研室负责人**在统一待办里看到“待审核资质”，点进去核对图片，审核通过或退回补充。
3. 退回后教师补材料再提交。每次修改都留历史版本，已用于归档考核的资质不会被覆盖。
4. 审核通过的资质算入“双师型”统计；快到期的（默认30天内）在待办里提醒。

### 3. 社会培训积分：项目结项 → 本人申报 → 四级审批 → 入账

1. 项目结项后15个工作日内，**教师**在“个人培训”点“申报本人积分”。
2. 审批顺序：**院长初审 → 继续教育学院复审 → 分管副校长审批 → 教学秘书归档**。每一级都能退回补正，申报人本人回避。
3. 归档后计入个人积分台账，计算依据（核算单元、人次、标准班、层级、场景、公式）全部留存，以后不能直接改。
4. 有错只能走“追加更正”，再走一遍审批，追加差额，原记录保留。
5. 教学秘书按双月生成汇总，年度公示5个学校工作日，期间可提异议。

### 4. 三级考核（教师）：自动取数 → 教师确认 → 教研室确认 → 学院确认 → 学校审核 → 归档

1. **学校**配置考核周期、指标、权重、评分规则（可复制上一周期的规则再改，可试算）。
2. **学校**点“生成/重算教师考核”，系统从培训数据、资质、积分里自动取数打分，每项都能看原始值、来源、规则和计算过程。
3. **教师**确认本人结果；有疑问就“提出核对”，没解决之前不能往下确认。
4. **教研室负责人**确认 → **学院**确认 → **学校**审核 → 归档。任何一级都能退回，退回原因留痕。
5. 归档后形成快照，以后规则变了也不会改写。结果可排名、导出、打印。

### 5. 学院年度考核与学院台账

1. **二级学院**把《社会培训人次统计表》上传到“学院台账与口径检查”，系统逐行复算、标出口径问题（漏除8、浏览量当人数等）。
2. **继续教育学院**逐行核定人次，可登记学校人工核定数和系统对比。
3. **学校**下达各学院年度目标（收入、人次、重点群体）。
4. 学院年度自评 → 财务、成果、纪检、归口核验 → 委员会评分并公示5个学校工作日 → 处理异议 → 归档。
5. 教研室平均积分（占教研室年度考核10%）由系统按教研室自动算，教研室负责人只看本室。

### 6. 数据对接（三个外部系统）

| 系统 | 方向 | 现在的状态 |
| --- | --- | --- |
| 学校统一认证（CAS） | 学校 → 本系统登录 | 适配层已做，学校给了地址和厂商手册，还没真联调 |
| 学校数据中台 | 学校 → 本系统（人事、收入、人次、项目、课程） | 适配层、字段映射、批次和重试都已做，学校还没给接口文档 |
| 湘培直通车 | 本系统 → 省平台 | 同步任务、逐笔结果、失败重试和补传已做，还没拿到省平台接口 |

管理员在“对接与同步”看每个接口最近一次同步时间、成功和失败数量、失败原因。

## 四、贯穿所有流程的规矩

- 每个关键操作都要写原因，系统记下操作人、时间、改前值、改后值。
- 所有附件跟业务和权限绑定，下载时再查一次权限并留痕。
- 统一待办把资质审核和到期、考核确认、数据核对、同步异常、项目备案结项、积分认定等集中在一处，点“去办理”直接跳到对应详情。
- 已归档的结果只能追加更正，不能直接改。
