# 本院人员授权浏览器验证（2026-11-02）

环境：本机虚构实验环境 `本地测试环境/.runtime/integrated-help-20261022`。用 synthetic.sqlite 在 http://127.0.0.1:8794 启动 bc9d077 之后的代码，ND_ENV=test。账号都是实验环境里的虚构账号，不涉及学校正式数据。浏览器是 Playwright Chromium 156，用无头模式实际点击页面。

## 院长（collegehead，测试学院一在任院长）

1. 从侧栏“工作台 → 本院人员授权”打开页面：显示“学院经办人”和“教研室负责人”两块，正常。
2. 点“添加经办人”：弹出候选列表，只列出本院老师（测试教师一 J001），到期日默认是本学年末。
3. 选测试教师一，点“设为经办人”：提示“已设为经办人……”，名单显示“测试教师一（J001）· 至 2027-08-31”和“撤销”按钮。
4. 测试教研室一点“更换 / 增加”，选测试教师一，点“设为负责人”：负责人一栏多了这位老师。
5. 点这位老师旁边的“撤销”，确认撤销：负责人恢复原样。

## 经办人（teacher，测试教师一）

6. 登录后打开右上角身份菜单，出现“经办人”身份。
7. 切换到经办人身份：首页提示“你正以学院经办人身份代 测试学院负责人 办理，办理记录会写明代办”，待我办理显示本院 2 项待结项。
8. 待办中心、三级考核都能正常打开。
9. 侧栏没有“本院人员授权”；直接打开 #collegestaff，页面提示“当前账号未授权访问此页面”（后端 require_dean 也会拒绝经办人）。这符合设计：经办人不能再往下指定。

## 收尾

10. 院长撤销测试教师一的经办人身份，名单恢复成验证前的样子。
