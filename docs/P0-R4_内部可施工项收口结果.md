## 本轮继续收掉的采购差异

1. 教师授课/业务事实与教师本人参训记录分离；参训学时不计入授课贡献。
2. 项目、课程、班级独立主数据底座；旧业务流水在 0002 中安全回填主数据，不臆造参训历史。
3. 学校数据中台入站支持字段映射、预览、逐行错误、明确确认和正式主数据；教师组织/启停变化使旧会话失效。
4. 字段映射按“接口 + 数据类型”生效，禁止把 SSO/中台/湘培目录混用；空映射不能被本地校验误判通过。
5. 数据中台内部具备 FULL 全量、INCREMENTAL 增量、人工拉取、定时计划四种模式；计划仅在真实 CONNECTED + 拉取适配器存在 + 学校管理员显式批准自动入库时可启用。
6. 定时批准人停用/降权、接口掉线或拉取适配器不可用时，计划自动停用并留痕；接口质量错误只保留预览，不写正式主数据。
7. 首次空校初始化自动登记 SSO / 学校数据中台 / 湘培三类接口，初始均 NOT_CONNECTED。
8. 统一认证增加身份字段本地映射准备，但没有猜测 CAS/SAML/OAuth2/自定义协议，也没有假登录。
9. 学校真实积分/考核双轨比对增加正式 XLSX 模板和机器校验脚本；没有学校确认人和显式签认时即使数值一致也不放行。
10. 开放格式移交继续覆盖 HR 主档、项目/课程/班级、参训、入站批次、同步逐笔日志、定时计划及交付配置；独立移交校验结果 PASS，但明确不等于灾备恢复证明。
11. 生成可重复 API 接口目录；生产 Swagger 保持关闭。
12. 用户手册、管理员手册、部署/恢复、接口联调、数据字典/移交、测试验收、试运行、问题整改和 SLA 模板已收齐。
