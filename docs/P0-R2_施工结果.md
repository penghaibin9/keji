# P0-R2：认证、权限与教师业务链施工结果

日期：2026-09-17。基线：P0-R1 源码检查点。裁决：**施工检查点；不允许作为学校生产部署包。**

## 1. 本轮实际推进

从真实 P0-R1 ZIP 校验并解压施工。原 `models.py`、R1 `services.py`、`frontend/app.js` 和 `frontend/scope.js` 字节保持不变，原教师评分、资质取数、积分追加差额函数没有另起一套。

原缺件没有完整原始归档可恢复。本轮按既有模型、前端调用与采购约束新写认证、权限、输入契约和业务路由，明确标为 **NEW_IMPLEMENTATION**，不冒充找回原文件。原缺件清单中的14个文件已补写；剩余8个部署配套文件及原Alembic图仍阻断生产。

### 认证与四级权限

实现实际同源Cookie会话，不使用Bearer替换原前端。账号登录、初登改密、退出、会话过期、账号停用、密码重置、角色变动和组织调动均连接数据库。会话只保存随机令牌的SHA256；新密码使用Argon2id；每次请求按当前组织和角色重新构建授权范围。

写操作检查来源与CSRF；用户输入权限不能越过角色上限；学校管理身份不跳过数据范围；禁止撤销最后一个可用学校管理员。新增账号与原历史账号密码兼容是不同事项：**未确认的旧密码哈希格式不接受、不自动覆盖，仍需明确迁移策略。**

### 培训数据、资质与附件

正式台账、明细、更正版本、统一统计、资质新建/变更/提交/退回/重提/审核、到期和核对待办均接入真实应用。上传实际PNG/JPEG/PDF字节，文件随机存放、限制大小、解析格式、校验SHA256；查看和下载重新检查登录、业务对象、当前组织、权限、长度及hash。移除当前关联保留历史材料。

附件先授权再解析；关键业务事务失败时清理本次新写附件。真实测试发现通用上传路由截获 `/attachments/{id}/detach`，已调整路由顺序并复测。旧失败日志保留。

文件校验不等于恶意软件扫描认证；更复杂恶意PDF解析资源治理仍需后续完整安全评估。运行代码的PDF结构检查使用pypdf，不依赖PyMuPDF。

### 教师积分与考核

规则草稿、复制新版本、样本试算、指纹匹配、100权重启用及停用接入服务端；复用原规则计算，不擅自改变学校口径。积分实际写流水，支持指定教师/项、本人确认、授权留痕解锁、正负人工更正、再次确认；每次确认保存当时流水和总分，后续调整不覆盖确认历史。

教师考核实现“教师本人确认→教研室→学院→学校→待归档→归档”的服务端流转。不能跳级、不能代本人确认或自我审核；未解决异议阻止确认/归档。人工分值更正保存原指标与追加项；归档保存规则、数据、过程快照和SHA256。归档快照版本与最终对象版本一致，随后资质变更不改变旧归档。

**教师业务链已接回，不代表学校/学院/教研室自身的独立考核已完成。独立组织考核仍未新建模型、迁移、接口或页签。**

### 查询、配置与事务

R1的统一查询已接到统计和正式考核列表，支持业务范围、周期、退回等筛选。原前端12项查询上下文回归仍通过。组织、账号、角色、周期、原三类设置、通知、审计、连接/任务只读状态可通过真实API访问。

关键业务、审计和幂等回执在同一事务提交；普通访问日志失败不反向更改成功业务响应。针对关键审计失败、同key重放、同key不同输入、双请求并发、角色撤权、组织调动、文件篡改和符号链接等执行反向测试。

当前写命令共用计算保护行，优先保证串行正确性；**没有宣称该锁粒度已满足100并发写性能**。MySQL锁、隔离级别、授权和灾备仍需真实环境测试。

## 3. 浏览器阻断与外观修复

当前Chromium管理员策略拒绝全部地址访问。本轮没有改策略，没有用API桥接或假响应绕过并声称浏览器成功。服务端实际HTTP可达不代表浏览器可达。

另以不发任何网络请求的方式渲染当前代码的 `loginView()`，仅检查登录页外观。发现390px下布局实际扩为410px；修复了grid子项最小宽度，不用隐藏溢出掩盖问题。保留前后截图与失败记录。这项**不能替代四角色Cookie、导航、上传、打印浏览器验收**。采购重点仍是PC，窄屏修复只是现有页面小修，不是新增移动端项目。

## 5. 可重复运行范围

在有Python3.13、Node22及测试依赖的独立Linux开发环境：

```bash
bash scripts/run_r2_tests.sh
```

要执行原生HTTP合成样本链（只监听127.0.0.1:8768，拒绝占用端口，不覆盖现有数据库）：

```bash
bash scripts/run_r2_http.sh
```

脚本启动新临时测试数据库，结束停止自己启动的服务；样本目录保留，不打进源码包。不能将这些命令当生产安装脚本。`backend/requirements.txt`记录本轮应用固定依赖；PyMySQL声明用于后续MySQL集成，当前执行环境未装该驱动、没有运行MySQL。没有完成全新空环境安装或依赖漏洞审计。
